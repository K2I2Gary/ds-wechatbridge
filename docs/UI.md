常用的直接露出，少用的收进「高级」折叠区；保存按钮固定在顶部，改完随时能存。

## 七个模块

| 模块 | 放什么 | 说明 |
|---|---|---|
| **连接与启动** | 自动化库 / 虚拟环境 / 桥接状态、装依赖、启动、停止、微信语言 | 原来的「一、装依赖」和「二、启动桥接」合并；解释器、安装日志、进程日志收进高级 |
| **接收与绑定** | 总开关、试运行、默认会话、只听名单、单独绑定、屏蔽、令牌 | 原来的「三、接到哪间会话」；令牌收进高级 |
| **人格与说话** | 人格开关与已读状态、对话温度、主动搭话、空闲分钟/上限 | 人格文件、重提间隔、看图设置收进高级 |
| **群聊与记忆** | 群上下文、RAG、群回复频率、记忆管理、外人只能聊天、群聊日记、主人 | 本地知识库与联网搜索参数收进高级 |
| **图片管理** | 收到的图片缩略图、描述、聊天 / 发送人 / 时间；单张删除、清空全部 | 删除同时删文件（工作区副本 + inbound 原文件）和 JSON 记录 |
| **联网搜索（独立）** | 搜索框、条数、保存/抓取开关、历史搜索组、关键词权重条形图、要点 JSON | 不依赖桥接进程 |
| **测试与日志** | 测发、测收、桥接日志 | 日志折叠，默认收起 |

## 控件与行为

- **保存**：顶部吸顶条；有改动时按钮变成「保存设置」，没改动时是「已保存」。所有设置仍然是改完点保存才落盘。
- **高级折叠**：用原生 `<details>`，内容始终在 DOM 里，展开即可用；不影响保存。
- **会话下拉**：列出 DSH 里打开的和磁盘上持久化的会话；未打开的会标注「未打开，发送时会自动唤醒」。
- **重复绑定警告**：两个聊天选了同一间会话时红字提示，保存日志也会记一条——这种情况回复只会发回其中一个。
- **只听**：留空 = 全部；也可以点「最近来找过的」快捷按钮加入/移出。
- **单独绑定**：一行 = 一个微信聊天 → 一间 DSH 会话；半截行（只有聊天名或只有会话）保存时会被拦下。
- **微信语言**：自动 / 中文版 / 英文版；桥接每 30 秒拉一次配置，切换不用重启桥接。
- **图片管理**：收到的图片复制到会话工作区的 `wechat-images/`；网格预览支持 GIF 动画。删除 / 清空全部会同时删文件、`wechat-inbound` 原文件、`wechat-image-memory.json` 记录；只允许操作图片记忆里登记过的路径。`.wxgf`（HEVC 图片）预览时自动转 PNG（需要 imageio-ffmpeg，装依赖时会一起装）。
- **清除上下文记忆**：显示本地库的消息 / 笔记 / 联网摘要条数；可以只清某个聊天，也可以清空全部。
  - 「清除这个聊天的记忆」只删该聊天在 `messages` 里的记录，其他聊天和笔记保留。
  - 「清空全部本地记忆」删除 `messages` / `notes` / `web_info` / 搜索组与关键词；有确认提示，不能撤销。
  - 只动本地 `wechat-bridge-memory.db`，不碰微信自己的数据库；清完 RAG 和 `local_search` 从空开始，新消息会重新入库。

## 自测覆盖

`_selftest_client.mjs` 用假 React 把设置页完整渲染一遍，覆盖：

- 第一帧、拉取 `/state`、脏数据不被轮询冲掉
- 屏蔽：输入框、回车、标签、保存
- 单独绑定：最近联系人一键绑定、刷新不丢、保存带默认会话、半截行拦截
- 只听：快捷加入、手打加入、标签、保存
- RAG、温度 0/1、主动搭话/本地库/联网搜索开关
- 人格文件路径、独立联网搜索组、关键词权重条形图、要点 JSON
- 本地记忆：统计显示、聊天下拉、按聊天清除请求
- 图片管理：区块渲染、描述显示、删除请求

所有断言在 1.9.6 重排后保持通过。
